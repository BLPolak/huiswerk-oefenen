§7.1 De vergelijking x² = c

c > 0 → twee oplossingen: x = √c  of  x = −√c

Voorbeeld: x² = 25 → x = 5 of x = −5

c = 0 → één oplossing: x = 0

Voorbeeld: x² = 0 → x = 0

c < 0 → geen oplossing (een kwadraat is nooit negatief)

Voorbeeld: x² = −9 → geen oplossing

Herleiden: ax² + b = c

① Haal b naar rechts: ax² = c − b
② Deel door a: x² = (c − b) ÷ a
③ Trek de wortel: x = √(...) of x = −√(...)
Voorbeeld: 3x² − 7 = 20
3x² = 27  →  x² = 9  →  x = 3 of x = −3

§7.2 Buiten haakjes brengen

Buiten haakjes brengen is het omgekeerde van haakjes wegwerken. Je schrijft een som als een product.

Regel: ab + ac = a(b + c)
De factor a is de gemeenschappelijke factor.

Aanpak in 3 stappen

① Zoek de grootste gemeenschappelijke factor (ggf) van alle termen
② Schrijf: ggf × ( ... )
③ Vul de haakjes in: deel elke term door de ggf
Voorbeeld 1: 6a + 10b  →  ggf = 2  →  2(3a + 5b)

Voorbeeld 2: x² + 5x  →  ggf = x  →  x(x + 5)

Voorbeeld 3: 6pq − 30p  →  ggf = 6p  →  6p(q − 5)

Tip: Controleer altijd door de haakjes terug weg te werken!

x(x + 5) = x² + 5x ✓
