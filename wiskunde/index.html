§7.1 De vergelijking x² = c

c > 0 → twee oplossingen: x = √c  of  x = −√c  (x²=25 → x=5 of x=−5)

c = 0 → één oplossing: x = 0

c < 0 → geen oplossing

Herleiden: ax² + b = c

① ax² = c − b
② x² = (c − b) ÷ a
③ x = √(...) of x = −√(...)
Voorbeeld: 3x² − 7 = 20 → 3x² = 27 → x² = 9 → x = 3 of x = −3

§7.3 De product-som-methode

x² + bx + c: zoek p en q met p×q = c en p+q = b.

Dan: x² + bx + c = (x+p)(x+q)

x²+7x+12: product=12, som=7 → 3×4 → (x+3)(x+4)

Tekens

c>0, b>0 → beide +   x²+5x+6=(x+2)(x+3)

c>0, b<0 → beide −   x²−5x+6=(x−2)(x−3)

c<0 → één +, één −   x²+x−6=(x+3)(x−2)

§7.4 Kwadratische vergelijkingen oplossen

A · B = 0 → A = 0 of B = 0

Aanpak

① Zet alles naar links (rechterlid = 0)
② Ontbind links als product (§7.2 of §7.3)
③ Stel elke factor gelijk aan nul
④ Los elke vergelijking op
x²+5x=0 → x(x+5)=0 → x=0 of x=−5
x²+x−6=0 → (x+3)(x−2)=0 → x=−3 of x=2
x²+3x=10 → ① x²+3x−10=0 → ② (x+5)(x−2)=0 → x=−5 of x=2

🆕 Gemengd — welke methode gebruik je?

x² = c  (geen x-term, c rechts)  →  §7.1: worteltrekken

3x²−7=20 → x²=9 → x=3 of x=−3

x² + bx = 0  (geen c, rechterlid nul)  →  §7.2: buiten haakjes

x²+5x=0 → x(x+5)=0 → x=0 of x=−5

x² + bx + c = 0  (drie termen, rechterlid nul)  →  §7.3+§7.4: product-som + product=nul

x²+x−6=0 → (x+3)(x−2)=0 → x=−3 of x=2

⚠ Niet in standaardvorm? Zet eerst alles naar links (… = 0) en identificeer dan het type!
