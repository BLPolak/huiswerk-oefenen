§4.1 Kwadratische formules

Een kwadratische formule heeft de vorm y = ax² + b. De grafiek is een parabool.

Berg- of dalparabool?

a > 0 → dalparabool ∪ (laagste punt)
a < 0 → bergparabool ∩ (hoogste punt)

Voorbeeld: y = 2x² + 3 → dalparabool (a = 2 > 0)
Voorbeeld: y = −3x² + 1 → bergparabool (a = −3 < 0)

y-coördinaat berekenen

Vul x in de formule in. Bereken eerst x², dan vermenigvuldig met a, dan optellen met b.

y = −2x² + 5 voor x = 3:
y = −2 · 3² + 5 = −2 · 9 + 5 = −18 + 5 = −13

Punt controleren op de grafiek

Vul de x-coördinaat in de formule in. Klopt de uitkomst met de y-coördinaat? Dan ligt het punt op de grafiek.

Formule y = 3x² − 1, punt A(2, 11):
y = 3 · 2² − 1 = 12 − 1 = 11 ✓ → A ligt op de grafiek.

§4.2 Rekenen met wortels

De wortel van een getal n is het getal dat je kwadrateert om n te krijgen. √25 = 5 want 5² = 25.

⚠️ De wortel van een negatief getal bestaat niet!
√−9 bestaat niet, want een getal maal zichzelf is nooit negatief.

Worteltrekken zonder rekenmachine

√(a · b) = √a · √b

Haakjes altijd eerst uitrekenen!
√(64 + 36) = √100 = 10
4·√9 + 3·√16 = 4·3 + 3·4 = 12 + 12 = 24
√(9 · 16) = √9 · √16 = 3 · 4 = 12

Kwadraten uit je hoofd

1²=1 · 2²=4 · 3²=9 · 4²=16 · 5²=25
6²=36 · 7²=49 · 8²=64 · 9²=81 · 10²=100
11²=121 · 12²=144 · 13²=169 · 14²=196 · 15²=225

(√a)² = a

(√a)² = a

Voorbeeld: (√7)² = 7    (√5)² = 5

§4.3 Wortelformules

Een wortelformule heeft de vorm y = a · √x + b. De grafiek begint bij x = 0.

⚠️ x mag niet negatief zijn!
Bij y = √x mag je geen negatieve x invullen.

y berekenen bij gegeven x

y = 3·√x + 2 voor x = 16:
y = 3·√16 + 2 = 3·4 + 2 = 14

Handige x-waarden voor tabel

Kies kwadraten: x = 0, 1, 4, 9, 16, 25
Dan is √x altijd een geheel getal.
