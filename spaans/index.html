SO Spaans  ·  2 juni  ·  Gramática — VTT
Structuur
VTT = haber (persoonsvorm) + voltooid deelwoord
Vervoeging van haber
yohe
túhas
él / ellaha
nosotroshemos
vosotroshabéis
ellos / ellashan
Regelmatig deelwoord
-ar werkwoorden → stam + -ado  (hablar → hablado)
-er / -ir werkwoorden → stam + -ido  (comer → comido)
Onregelmatige deelwoorden
decir → dicho
hacer → hecho
ver → visto
escribir → escrito
volver → vuelto
